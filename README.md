# C-For-Loop-Practice-Programs
This repository contains 4 basic C++ programs using for loop.  1. Sum of first 100 natural numbers 2. Multiplication table of a number up to 10 3. Sum of all even numbers between 1 and 50 4. Sum of all odd numbers between 1 and 50  These programs are for beginners to practice for loop, if condition and basic input/output in C++.
